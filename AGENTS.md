# Instructions for Codex and other agents

Code review in this repository follows `.github/copilot-instructions.md`. Read that file first and
apply it as written: what to report, what not to report, and how to behave on a re-review. It is the
one place the review rules live, shared with Copilot and with Claude Code's gate agents; do not add
rules of your own beside it.

The working rules (hard rules, stack, conventions) are in `CLAUDE.md`. How the agent teams build
this project, and what they must never do, is in `docs/agent-workflow.md`. All of it applies to you.
